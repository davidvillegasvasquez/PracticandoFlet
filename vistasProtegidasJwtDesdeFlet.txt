Implementar vistas protegidas en Django REST Framework (DRF) usando djangorestframework-simplejwt y consumirlas desde una aplicación Flet implica dos etapas principales: configurar el backend para autenticar mediante tokens JWT y configurar el frontend de Flet para almacenar y enviar ese token.

Parte 1: Configurar Backend (Django + DRF)
Instalar dependencias:

pip install djangorestframework djangorestframework-simplejwt

Configurar settings.py:

Añade las aplicaciones y configura la autenticación predeterminada.
python
INSTALLED_APPS = [
    ...
    'rest_framework',
    'rest_framework_simplejwt',
    'tu_app',
]

REST_FRAMEWORK = {
    'DEFAULT_AUTHENTICATION_CLASSES': (
        'rest_framework_simplejwt.authentication.JWTAuthentication',
    )
}

Configurar URLS para tokens (Login):
En tu urls.py, añade las rutas para obtener y refrescar tokens.
python
from django.urls import path
from rest_framework_simplejwt.views import (
    TokenObtainPairView,
    TokenRefreshView,
)

urlpatterns = [
    path('api/token/', TokenObtainPairView.as_view(), name='token_obtain_pair'),
    path('api/token/refresh/', TokenRefreshView.as_view(), name='token_refresh'),
    # Tus otras URLs
]
Crear una Vista Protegida:
Utiliza IsAuthenticated para proteger la vista.
python
from rest_framework.permissions import IsAuthenticated
from rest_framework.views import APIView
from rest_framework.response import Response

class VistaProtegida(APIView):
    permission_classes = [IsAuthenticated]

    def get(self, request):
        content = {'message': '¡Hola, usuario autenticado!'}
        return Response(content)
 
Parte 2: Consumir API desde Flet
Flet utilizará la librería requests para enviar el token JWT en el encabezado Authorization. 

Instalar Flet y Requests:

pip install flet requests

Estructura de la app Flet (Login y Petición):

import flet as ft
import requests

# URL de tu API Django
BASE_URL = "http://127.0.0.1:8000"

def main(page: ft.Page):
    page.title = "Flet + Django JWT"
    
    # Variable para almacenar el token
    access_token = None

    def login_click(e):
        nonlocal access_token
        try:
            response = requests.post(f"{BASE_URL}/api/token/", json={
                "username": username_input.value,
                "password": password_input.value
            })
            
            if response.status_code == 200:
                data = response.json()
                access_token = data['access']
                status_text.value = "Login exitoso"
                status_text.color = "green"
            else:
                status_text.value = "Login fallido"
                status_text.color = "red"
        except Exception as ex:
            status_text.value = f"Error: {ex}"
        page.update()

    def get_protected_data(e):
        if not access_token:
            data_text.value = "No estás autenticado"
            page.update()
            return

        headers = {"Authorization": f"Bearer {access_token}"}
        response = requests.get(f"{BASE_URL}/api/protegido/", headers=headers)
        
        if response.status_code == 200:
            data_text.value = response.json()['message']
        else:
            data_text.value = "Error al acceder a datos"
        page.update()

    # UI Components
    username_input = ft.TextField(label="Username")
    password_input = ft.TextField(label="Password", password=True)
    status_text = ft.Text()
    data_text = ft.Text()

    page.add(
        username_input,
        password_input,
        ft.ElevatedButton("Login", on_click=login_click),
        status_text,
        ft.Divider(),
        ft.ElevatedButton("Obtener Datos Protegidos", on_click=get_protected_data),
        data_text
    )

ft.app(target=main)

Puntos Clave
Encabezado Auth: El token debe enviarse como 'Authorization': 'Bearer <token>'.
Refresh Token: Si el access_token expira, usa el refresh_token obtenido en el login para solicitar uno nuevo a api/token/refresh/.
Seguridad: No guardes contraseñas en texto plano en la app Flet.
